## 🚀 Featured Projects

### 🧠 Synapse AI Tutor

An AI-powered learning workspace built around one principle:

> **Use AI to learn — not to avoid learning.**

Synapse is a vision for a complete study environment where learners can bring their own materials and turn them into interactive learning experiences.

| Learning tools | Study workspace |
|:--|:--|
| 📚 Structured notes from your material | 🎯 Distraction-free focus mode |
| 📝 Quizzes, practice, and written exams | 🔎 Search across chats, notes, and files |
| 👨‍🏫 Step-by-step AI explanations | 📖 Answers with source citations |
| 🧩 Active-recall exercises | 🧠 A persistent personal knowledge base |
| 📄 Work with common document formats | 🖼️ An AI-assisted canvas |

**Focus:** AI · Learning systems · Web SaaS · File intelligence

### 🤖 Vega AI LLMs

Exploring friendly, locally minded language models for coding and conversation. The long-term goal is an assistant that can run across everyday devices, including PCs, phones, and tablets.

**Model ideas:** `vega-1-tiny` · `vega-1-base` · `vega-1-tiny-thinking` · `vega-large-llm` · `vega-1-tiny-large`
